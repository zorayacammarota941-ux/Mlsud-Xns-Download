# Mlsud Xns

Mlsud Xns 是基于 Clash Verge Rev 2.5.2 定制的桌面代理客户端。

## 下载

安装包发布在本仓库的 Releases 页面：

- Apple Silicon：适用于采用 Apple M 系列芯片的 Mac。
- Intel：适用于采用 Intel 处理器的 Mac。

## 定制内容

- 应用名称改为 Mlsud Xns。
- 使用定制的 M 图标。
- 移除界面中的使用手册及设置页外部链接按钮。
- 禁用应用自身更新功能。
